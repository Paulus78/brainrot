# Model research snapshot — 2026-09-25

- OpenAI Sora 2 and the Videos API were shut down on 2026-09-24; the retained API reference states there is no one-to-one replacement API: https://developers.openai.com/api/reference/typescript/resources/videos/methods/create
- Current OpenAI image generation supports reference-image generation/editing with GPT Image 2.5 through the Images or Responses API: https://developers.openai.com/api/docs/guides/image-generation
- Current OpenAI speech generation uses `gpt-4o-mini-tts`, supports instruction-based tone control and WAV output: https://developers.openai.com/api/docs/guides/text-to-speech
- OpenAI lists `gpt-4o-mini-tts` at $0.60 per 1M text-input tokens and $12 per 1M audio-output tokens: https://developers.openai.com/api/docs/models/gpt-4o-mini-tts
- Google Flow UI inspection on this account showed Nano Banana 2 image generation at 0 credits, Veo at 8 credits for 4 seconds/360p and 24 credits for 8 seconds/720p. These are account/UI observations, not API pricing claims.
